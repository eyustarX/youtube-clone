# 🎬 YouTube Clone

A responsive YouTube homepage clone built with **HTML5** and **CSS3**. This project recreates the layout and design of YouTube's home page to practice modern frontend development techniques, including Flexbox, CSS Grid, and responsive design.

## 🚀 Live Demo

🔗 https://eyustarx.github.io/youtube-clone/

---

## 📖 About

This project is a frontend clone of the YouTube homepage. It focuses on building a clean, responsive interface that closely resembles the original website while strengthening core HTML and CSS skills.

> **Note:** This project is for educational purposes only and is not affiliated with or endorsed by YouTube.

---

## ✨ Features

- Responsive layout for desktop and mobile
- Navigation bar with search box
- Sidebar navigation
- Video cards with thumbnails
- Channel avatars
- Video titles, creators, and view counts
- Hover effects
- CSS Grid for video layout
- Flexbox for navigation and alignment
